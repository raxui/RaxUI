# Stepper examples

Install `stepper, field, input, button` and copy the Razor files in this directory together. Enable an interactive render mode for actions. Pass `Arabic` to localize the main examples.

Linear checkout with per-step validation, error focus and simulated confirmation; free onboarding with icons/optional step, vertical deployment content, narrow labels and Arabic navigation.

Static SSR shows initial progress/content and native links/disclosures where available. The checkout example is a local simulation; no payment or order is submitted.
