# Avatar examples

Install `avatar` and copy `AvatarExamples.razor`. Supply `/avatars/astronaut.jpg`, `/avatars/chelsea.jpg` and `/avatars/coffee.jpg` as in react-test. Covers images, broken-image and generic fallbacks, sizes/shapes, presence/ring, capped groups with hover expansion, reviewers and a comment row. `Arabic` localizes headings and status labels.
